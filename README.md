# Plant Disease Prediction

A deep learning project that classifies plant leaf images into 38 healthy and diseased categories using PyTorch.

## Dataset
This project uses the PlantVillage dataset.

- **Source:** [PlantVillage Dataset on Hugging Face](https://huggingface.co/datasets/mohanty/PlantVillage)
- **Classes:** 38
- **Image type:** Color (RGB) images
- **Dataset storage:** The dataset is not included in this repository because of its large size.

## Models
- Custom CNN architectures
- ResNet18 transfer learning

## Technologies
- Python
- PyTorch
- NumPy
- Matplotlib
- Scikit-learn
